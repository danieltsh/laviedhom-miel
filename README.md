# LAVIEDHOM — Catalogue de miel

## Objectif
Présenter les miels LAVIEDHOM et permettre aux visiteurs
de faire une demande de commande sur WhatsApp.
Les demandes sont également enregistrées dans un tableau privé.

## Parcours utilisateur
1. Découvrir les produits, leurs photos, formats et prix.
2. Choisir un produit et une quantité.
3. Remplir un formulaire obligatoire :
   prénom, nom, téléphone et e-mail.
4. Cliquer sur « Enregistrer ma demande et ouvrir WhatsApp ».
5. Enregistrer la demande dans le tableau de suivi.
6. Ouvrir WhatsApp avec un message prérempli.
7. Le client envoie lui-même le message.

## Fonctionnalités
- Présentation de la marque
- Catalogue de produits
- Interface adaptée aux mobiles
- Formulaire avec validation des champs obligatoires
- Enregistrement des demandes dans un tableau privé
- Message WhatsApp prérempli avec le produit et les coordonnées
- Confirmation de l’enregistrement de la demande
- Gestion des erreurs si l’enregistrement échoue
- Protection contre les soumissions répétées et le spam

## Tableau de suivi
Colonnes :
- Date et heure
- Prénom
- Nom
- Téléphone
- E-mail
- Produit et format
- Quantité
- Statut de suivi

Statut initial : Nouvelle demande.
Les statuts de suivi sont modifiés manuellement.
Une demande ne constitue pas une commande confirmée.

## Données personnelles
- Informer le visiteur de l’enregistrement de ses coordonnées
  et de leur utilisation pour traiter sa demande.
- Réserver l’accès au tableau aux personnes autorisées.
- Ne pas enregistrer de données clients dans le dépôt GitHub.
- Ne pas utiliser les coordonnées pour des communications
  commerciales non prévues dans le formulaire.
